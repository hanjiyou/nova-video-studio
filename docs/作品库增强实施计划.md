## 最终行为

### 日期筛选
- 默认全部日期，提供今天及自定义范围；采用此前建议的任务创建时间，与现有倒序一致，不因重新下载或归组改变。
- 今天与自定义自然日按操作者本地时区解释；开始日零点包含，结束日次日零点不包含。前端转换绝对时间，后端独立严格校验。
- 查询字段 createdFrom / createdBefore，均为UTC ISO字符串；分页前联合日期、分组、类型、关键词过滤，列表与total共用条件。保留unfilteredTotal原定义与分组总计数。
- 切换筛选回第一页、清空本页管理选择；无结果可清除筛选；开始晚于结束或日期缺失不得发送错误查询。今天状态跨本地午夜更新，迟到响应不得覆盖新条件。

### 多选与批量归组
- 选择粒度为稳定localTaskId的整任务卡，图片/视频均支持；与现有最多7张、有顺序的参考图选择独立。
- 多选入口、逐项勾选、全选当前页、清空、已选数量、退出多选；只选当前页，翻页/分组/日期/搜索/类型切换清空管理选择，不影响参考图顺序。
- 拖动任意选中项携带冻结的整批ID，显示叠放封面与数量；未选项不得意外携带隐藏旧选择。“移动到分组”与拖拽共用处理。
- 全部作品不能投放；归档/待恢复组不可接收；在途IO与迁移保护保持，后端仍是最终判断。已在目标组的项明确跳过。
- 逐项调用现有moveTaskGroup幂等接口，不新增通用队列/全批事务。固定本批范围、归属版本和目标，每项全部输出独立原子移动，保护共享引用及原件。
- 显示已处理N/总数和成功/失败/跳过；失败保留选择与原因，不撤回已完成项；未知回执保留原请求核对，禁止新请求盲重做。重复点击/投放不得并发再搬。
- 活动批次锁定会改变范围/目标的操作；卸载后停止派发后续项，已发出单项由原服务恢复，不谎报全批成功。不新增批量删除。
- 移动前停止预览并释放文件句柄，避免Windows占用；完成同步列表、计数及预览引用。

### 悬浮预览
- 仅作品库视频封面停留约250ms后原位静音循环；最多一个，快速划过不启动；双击/键盘仍打开大预览。
- 移开停止并恢复起始封面。翻页、筛选、失焦、页面隐藏、离开视口、拖拽、多选管理、弹窗、卸载均终止；迟到play/加载不得重新启动。
- 使用受管本地previewUrl，不触发生成、上游下载、转码或自动重下载。缺失/解码错误简明提示，保留其他操作。
- 控制源附着、预加载及活跃解码。当前Range每次整文件读取+校验，需要有界、保留完整性和受管路径校验的最小优化。
- 有界验证缓存/安全句柄取最小完整方案，必须失效于外部文件改变/根目录/归组变化；覆盖损坏、替换、缺失、Range/HEAD/If-Range及释放。不开放任意路径、不无限缓存视频。
