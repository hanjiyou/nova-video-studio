## 原因与行为

应用 update-service 已设置 autoRunAppAfterInstall=true，并调用 quitAndInstall(false, true)，即交互式安装、请求重新启动。但基础 electron-builder.yml 的 runAfterFinish=false 被更新包继承，导致完成页不显示运行应用选项。锁定依赖的 assistedInstaller.nsh 仅在未定义 HIDE_RUN_AFTER_FINISH 时生成启动复选框；installSection.nsh 的 --force-run 在交互式向导下不会直接启动应用，仅在静默安装时执行。因此仅设置 updater 参数无法弥补缺失的完成页选项。

builderConfiguration 现对 github-test 与 release 显式设置 runAfterFinish=true，显示默认勾选的运行应用选项；点击“完成”才启动，取消勾选则不启动。local-test 保留手动启动，避免旧隔离验收的自定义资料目录丢失。没有改为静默安装或强制绕过用户选择。
