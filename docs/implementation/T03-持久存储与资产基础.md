## 实现

详见 [存储契约/API说明](../storage-v1.md)。

| 文件 | 行为 |
| --- | --- |
| [migrations.js](../../backend/storage/migrations.js) | v1登记现有任务结构，v2添加schema_migrations、连接版本占位、快照/事件/资产/有序关联/草稿/设置；在线一致备份、独立quick_check和SHA、全部待迁移版本单事务、失败回滚、未知schema/checksum拒绝 |
| [store.js](../../backend/storage/store.js) | UUID资产、内容寻址/原字节复制、fsync与不覆盖原子发布、可信根内读取和摘要校验；事务引用/快照/草稿/设置；明确missing/corrupt且保留记录 |
| [http.js](../../backend/storage/http.js) | 仅桌面启用，经T02鉴权的资产导入/元数据/内容、分模式草稿、窄设置、分页历史及事件；不接收路径、不返回request_json/Key/credentialRef |
| backend/server.js | 桌面迁移完成后才监听；参考输入入队前持久化，任务快照固定，实际生成输出写受管对象并为旧URL建立别名；桌面ACK/TTL/启动判死/失败删图隔离，Web原路径保留 |
| backend/plugin-runtime/media.js | 桌面上传直接写受管资产、同素材可被多个任务引用；失败/TTL不删除共享对象；Web仍按原临时素材语义 |
| desktop/ipc.cjs / preload | importReferenceAssets()无参数，宿主系统选择PNG/JPEG并事务导入批次，只返回摘要；实际webContents/frame验证；没有任意文件路径或通用文件操作接口 |
| electron-builder.yml | 明确包含backend/storage/**，测试/脚本不入包 |

数据布局为userData/nova-tasks.sqlite、backups/和storage/assets/，端口只决定服务地址，不决定元数据或文件位置。新桌面生成与插件上传只创建受管对象及数据库别名，不覆盖相邻兼容目录中已有的未知文件。原字节没有重编码、缩放或转换WebP。

迁移前一致快照包含已提交WAL页面；备份失败不执行DDL，任一步SQL失败回滚所有待迁移DDL/数据/版本登记。重复启动版本不重复应用，也不重复备份。未知库、历史checksum不匹配、未知已有对象保持原状。schema版本事务不等于跨文件系统事务：导入批次失败可留下无引用的受管字节，但元数据/引用回滚；本阶段不做自动GC，避免误删共享输入。

任务/连接版本有不可变约束；草稿变更不回写任务快照。localRequestId唯一列只是T05前置，不等于已经实现重传去重返回逻辑。任务事件记录旧状态观察，不冒充新状态机。旧前端仍有其IndexedDB/本地缓存，尚未全面接入新API，不将旧UI导航草稿、作品列表或真实生成流程标为已完成。

- 本次复验并行运行多个本地服务时，实际Electron启动返回EADDRINUSE，退出1；[原始检查日志](t03-evidence/native-storage-port-conflict.log)及[实际stderr](t03-evidence/native-storage-port-conflict-stderr.log)保留。其他服务结束后，以全新profile顺序重跑，首次8项及重启9项均通过；未放宽端口或退出检查。
- 新增测试一处SQL字符串引号、显示名控制字符正则lint、Windows asar审计路径分隔符分别修正；未放宽生产主机限制、鉴权、完整性或exit检查。

availability=available只代表文件存在；所有新资产validationState仍为unverified，T08负责媒体完整解码、下载原子落盘/Range/视频时长等。旧图片兼容流程仍沿用其旧completed状态，未用本阶段存储检查替代T08本地完成定义。100MiB/32引用为应用预算，不冒充供应商支持范围。JPEG宽高、视频时长未伪造。

本阶段没有自动恢复或补发创建；重启仅保留原任务状态和ID，T05负责恢复/暂停语义。现有Key仍走原临时内存兼容入口，T04负责替换；新草稿/设置/事件不接收凭据字段。upstream_task_id列和历史摘要中的upstreamTaskId目前只是结构占位；旧插件上游ID仍在request_json中，T05统一恢复字段。本阶段不承诺这些历史摘要字段已经补全。输出目录版本只是结构占位，未假装完成可变目录快照与另存交互。未引用对象的安全回收、完整用户删除流程在后续作品库/媒体服务阶段明确。
