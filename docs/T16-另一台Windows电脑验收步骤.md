# Nova Studio 3.4.0.17 另一台 Windows 电脑验收

仅供用户自己的另一台电脑/虚拟机受控测试，不公开分发。普通账户、独立无开发工具环境尚待实测。应用内部版本3.4.0，测试安装包文件版本3.4.0.17，安装名称Nova Studio T16 Followup；不覆盖上一轮Nova Studio Offline Test安装。

1. 在Windows 10/11 x64的普通账户登录。记录系统版本、是否安装Node/Python/FFmpeg及是否使用虚拟机。把整份资料解压到一个可写、包含中文和空格的目录，例如“下载\Nova 测试 资料”。不要放到程序安装目录。
2. 安装Nova-Studio-3.4.0.17-offline-test-x64.exe，选“仅为我安装”和普通用户可写的新目录。记录退出/报错及系统“已安装的应用”中是否出现Nova Studio 3.4.0.17 - T16 Follow-up Test。未签名包按本机正常安全策略处理；遇阻止请保留错误，不改系统策略。
3. 双击Start-Clean-Test.cmd。默认路径不同则把安装目录内的Nova Studio T16 Followup.exe拖到这个CMD上。不要直接双击EXE，以免使用已有默认资料。空白引导选择暂不配置，写一段草稿、关闭，再用同一CMD重开，确认草稿保留。无需真实Key，也不要点击生成。
4. 关闭应用，双击Start-Isolated-Test.cmd（自定义安装同样拖EXE到CMD）。作品库有4条明确标为“既有真实样本”的验收记录：一张图片、文生/单图/双图各一段真实视频。这些文件来自此前已完成的生成，验收记录由工具重新建立，不冒充此机生成或原始任务恢复证据。
5. 打开图片、放大；依次预览三个视频，播放/暂停、跳到中间、调音量、全屏后退出。三个现有视频均1280×720、约6.04秒；文字视频的分辨率由服务决定，该样本尺寸不代表请求保证。核对界面元数据和实际播放，并记录是否有错误。
6. 图片和视频分别点另存：选中文/空格路径；再次保存到同名文件，分别检查取消和确认覆盖；确认文件存在且不新增生成。点打开目录，检查Explorer确实选中当前文件；在设置导出脱敏诊断，检查另存/取消正常。拖动标题栏，并测试最小化、最大化、还原、关闭。
7. 只保留此测试应用运行，用任务管理器结束这个测试应用，再用同一CMD重开。确认4条验收记录、媒体和草稿仍在。关闭应用后再次运行同一安装包覆盖，再重开确认保留。此项是同版本更新，不证明正式身份跨版本/schema升级。
8. 可在Windows设置卸载该测试应用，再安装、同一CMD启动确认资料仍在。保留资料目录，绝不删除此前APPDATA/nova-image；卸载只针对Nova Studio T16 Followup。最后填写本页末尾记录。

默认安装路径为%LOCALAPPDATA%\Programs\Nova Studio T16 Followup。CMD只为自身进程指定旁边的Clean-Profile或Test-Profile，不改变全局环境，不读取其他软件资料。Test-Profile初始没有连接、凭据、远端URL、原始远端任务ID或绝对输出路径，首次启动时自动绑定本机目录。拷到第二台机器时请重新解压原始未运行资料，避免带入第一台已初始化的路径。

若无法启动，记录时间、完整可见错误、应用/安装版本和事件查看器Application Error 1000/Windows Error Reporting 1001中对应记录；保留资料。Codex受限令牌曾出现0xc0000135，官方Electron同样失败，尚无具体缺失模块证据；不能把该令牌等同普通用户，也不据此禁用sandbox。后续按实际错误提供官方Electron基线比对。

本机实现方已完成的安装态API验收与人工结果分开记录。本表执行后才可能关闭普通账户/干净环境和系统人工交互缺口。FFmpeg完整对应源码/补丁/构建材料及旧NSIS堆异常根因仍为发布门槛；本资料不授权公开发行。
