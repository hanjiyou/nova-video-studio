## 协议依据与受控许可

桌面已有 OpenSosen 说明仅证明原服务、精确 1.5 型号的单/双参考 multipart，不覆盖纯文本视频。2026-10-24 只读原服务公开 `/api/status` 和 `/api/pricing`：`docs_link` 为空；flare 明确列出 `image-generation` 并映射 `POST /v1/images/generations`；两视频型号只列出 `openai`→`/v1/chat/completions`。这个泛用目录不足以推导视频的精确消息格式、附件或返回语义，故没有删去参考图猜文生协议，也没有盲试 chat 接口。

flare 首次成功前仍是候选最小 JSON。为进行这次用户明确授权的验证，增加仅由主进程一次配置的受控许可，绑定连接版本、能力版本、本地请求 UUID、提示词 SHA-256，并仅允许精确原服务/型号的无图、无额外参数请求。持久化创建账本一旦占位，许可预算回调立即关闭。正常桌面启动、HTTP、renderer 或环境变量均不能配置许可；真实成功不直接改写历史能力记录。本次改动在使用前已向主会话报告，相关定向回归通过。生产能力仍为 `unverified`，等待主会话对真实证据和正式开放范围的审查。

所有真实生成请求均进入生产的桌面会话认证 `/api/nova/workbench/tasks`，使用现有适配器、单生成队列和生产本地媒体验证。没有直接调用 `enqueue` 跳过入口校验，没有改适配器协议或下载/DNS/认证转发保护。单/双参考的固定 `seconds=6`、`size=1280x720`、原 PNG 字节和顺序在网络提交前校验。
