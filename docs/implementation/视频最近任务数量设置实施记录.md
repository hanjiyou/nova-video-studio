## 行为与实现

设置页新增独立紧凑“工作台显示”区，“最近视频任务数量”默认 6，可保存 1–100 整数。保存成功后立即用于视频列表及“处理中 / 等待处理”两项统计，并随本地 workspace setting 跨重启保留。旧配置缺字段仍读 6，图片继续显示最近 6 条，作品库分页及此前预览行为保持。

- `backend/storage/store.js`：workspace exactKeys 增加 recentVideoTaskLimit；只接受数值型 1–100 整数，保留原 expectedRevision 冲突检查。复用既有 app_settings，不追加迁移、不改变执行并发设置。
- `frontend/src/lib/workbench-client.ts`：WorkspacePreferences 增加可选 recentVideoTaskLimit，统一读取缺省值 6；保存仍使用原窄 setting API。
- `WorkbenchShell.tsx`：将既有 workspace 串行队列提取为小型 queueWorkspace，导航、新数量保存和显式重读共用同一队列。保存时合并最新 ref 与 patch，保留 activePage / activeMode / returnPage / wideMode。原导航失败提示与更新前 flush 继续保留。列表和两项统计共用 recentTasks，视频用配置、图片 6。
- `RecentVideoTaskSettings.tsx`：独立显示控件与保存 / 重新读取；空、非整数、越界中文提示。失败保留输入并不显示成功，revision 冲突须重读；dirty / pending 复用 useUpdateBlocker，更新冻结时不操作。成功回执需由 Shell 确认保存字段等于请求值。
- `useWorkbenchTasks.ts`：视频请求 limit 使用已保存数量，20 不会被旧 limit12 截断；图片读取仍 12、展示仍 6。配置改变触发刷新；在途旧请求用 kind / limit 核对，迟到结果及错误不覆盖新查询。loading 期间合并一次补读，旧请求结束立即读取最新值，不等待 5 秒定时器。手动选择的较旧任务继续由原详情路径读取，缩小列表不清除它。
- `globals.css`：仅为新数字控件增加 240px 最大宽度；沿用现有表单、按钮和面板样式。

未改下载、计费、执行并发、作品库预览组件或后端媒体服务；保留前轮审核记录原文。既有 desktop/credential-vault.cjs、backend/temp/ 和历史未跟踪证据不属于本轮，未修改或暂存；暂存区为空。
