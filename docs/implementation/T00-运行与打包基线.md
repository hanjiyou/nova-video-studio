## 实际启动与原生依赖

[verify-desktop-baseline.cjs](../../scripts/verify-desktop-baseline.cjs) 启动真实 Electron，使用首次运行数据、临时 loopback 端口和应用已有的显式 CDP 开关。验证通过 CLI 与本机 HTTP/CDP API 完成；没有启动 Computer Use 或桌面操作浮层。

两种启动均检查了：

- `/api/nova/config` 和 `/api/nova/queue-status` 返回 200，队列没有任务。
- 页面完成加载、初始遮罩移除、真实正文存在，preload 返回 Electron 43.4.0 版本。
- 渲染层 `typeof require`、`typeof process` 均为 `undefined`，观测期间没有未捕获的 renderer 异常。
- 关闭实际浏览器窗口后 Electron 正常退出，退出码 0，没有强杀清理标记；关闭时 CDP socket 断开是预期响应。
- 内嵌后端真实创建 53,248 字节数据库，存在 tasks、task_items、plugin_media 等表；退出后只读执行 `PRAGMA quick_check` 返回 `ok`。

开发态使用隔离的 `NOVA_DATA_DIR`。安装态专门移除该覆盖，验证原版默认 `<安装目录>/data/nova-tasks.sqlite`；安装位置 `temp/t00-baseline/installed-中文 路径` 包含中文和空格。此处是可写测试位置，不能据此声明安装到不可写目录也可靠，系统 userData 改造仍属于 T02。

原项目 `npmRebuild: false`。本次没有重建或替换原生依赖，Electron（Node 模块 ABI 148）实际运行内嵌后端并创建数据库；系统 Node ABI 为 137。打包后的 `app.asar.unpacked/node_modules/better-sqlite3/prebuilds/win32-x64.node` 与 npm 原件哈希一致：`e21e5efd71fba66578e95b62554d9028064a80dafd7221bf8a8ef155de8d240a`。这些实测支持当前锁定的 N-API 预编译包与 Electron 兼容。Electron 的 `process.versions.sqlite` 属于其内置 SQLite，不能替代 better-sqlite3 的实际查询值。

## 原有失败、警告与边界

应用测试和构建没有失败项，也没有为 T00 修改业务逻辑。记录的环境失败及原有警告如下：

1. 官方 Electron 下载源超时，已通过同版本、官方校验一致的镜像完成；首次冷环境仍需可访问的下载源。
2. 前端测试有原有 React `jsx` 属性警告、测试环境插件相对 URL 解析错误；672 项仍全部通过，保留原始日志，T00 不扩展修复。
3. electron-builder 提示缺少 author、使用默认图标，配置关闭资源编辑和签名。日志中的 signing 阶段不表示实际签名成功，Authenticode 检查为 NotSigned。
4. 安装版退出 stderr 出现 `fs.Stats` 弃用提示和 GPU 关闭阶段日志，页面、数据库和退出结果通过。见 [installed-stderr.log](t00-evidence/installed-stderr.log)。
5. 当前仍是原版 Nova。默认 Agent 入口、原队列、凭据/任务恢复/持久化问题均留给已规划阶段，此次只验证运行和打包基线。
6. 本阶段未验证实际生成、参考图效果、视频播放、普通账户、无开发环境机器、升级和完整 61 项交互。这些仍属于后续阶段，不能用本记录宣布最终交付。
