## 1. 已确认的需求与界面

图片生成、视频生成共用“作品名称（可选）”，放在现有描述输入之前；保留左参数、右预览、最近任务布局。复用当前深色紫色主题及既有组件，不重新设计整个工作台。名称最多 60 个 Unicode 字符，去除首尾空白，拒绝控制字符；允许中文、空格、重复名称和普通标点，不调用 AI 取名，不发送名称给模型。

名称随分组、模式草稿保存，切换和刷新不得丢失；沿用现有草稿保存反馈，不增加频繁弹窗。提交时冻结原始名称，当前名称独立维护。失败、取消、成功记录都保留名称；复用参数带入当前名称。卡片、最近任务、全部任务、作品预览及详情采用“当前名称 → 提示词 → 固定缺省文案”；完整提示词独立保留，复制提示词不会改为复制名称。

已审阅原型位于本轮会话设计目录 nova-naming-design-20261105-v1（生成、作品库、重命名三视图）。原型中的“仅修改展示名称”文案已被本节同步文件规则替代，最终审核以实际组件为准。

作品库更多菜单、预览与任务详情提供命名/重命名入口。弹窗显示当前自定义名称、字符计数，并明确同步本机文件名。清空名称恢复提示词展示与提示词摘要文件名；生成/下载等真实文件 IO 在途时禁用，说明结束后可修改。保存中防重复操作，成功刷新列表与详情；失败保留输入和可操作提示，不伪报成功。

## 2. 搜索规则

输入按全部空白字符分词，忽略首尾和重复空白，关键词顺序不限。每个词在同一作品的当前名称、提示词、模型任意字段字面包含即匹配；词间 AND、字段间 OR。

例如“镜头03 行李箱 grok”与“grok 镜头03 行李箱”等价，可以分别匹配名称、提示词和模型。百分号、下划线和引号视作普通字符；不引入字段前缀、自动中文分词、同义词或模糊拼音。沿用现有大小写匹配策略。空搜索显示全部，与日期、类型、分组、分页和计数共同生效。改名前旧名称不继续参与搜索。

## 3. 文件命名和兼容

- 新任务填写名称时：`安全名称_原创建时间_稳定防重编号[_输出序号].真实扩展名`。名称置前，保持可读；无名时沿用原提示词摘要规则。
- 旧作品没有明确命名操作时，展示与文件保持原样；用户补名、再次改名，新旧作品都同步修改正式输出文件名。
- 时间来自原任务创建时间；防重身份基于稳定任务/输出身份，修改名称不换时间和编号。多输出有序区分，重复名称、同秒提交仍可共存。
- 展示名称保留合法输入，文件名清理 Windows 禁止字符、尾点/空格等；只裁可读名称，保留后缀和扩展名，遵守文件名 100、完整路径 240 UTF-16 单位上限。不能信任用户输入的扩展名。
- 同目录真实文件和数据库预留都检查冲突，冲突追加序号；独占发布不覆盖其他文件。重新下载沿用已登记位置，不重复生成。
- 旧摘要路径补名原则上原目录改名，不暗中搬到新分组；新可读旧路径需要精确登记与受管校验，不能全局放宽任意路径访问。
- 作品改名覆盖全部正式输出及相关已保存检查点。共享素材和不可变输入引用受保护：必要时为当前作品复制并重新关联，其他引用保持可读，证明无引用才清理原文件。
- 文件改名与元数据通过已有持久操作日志协调；提交前失败回滚，提交后中断可恢复，保留有歧义/被占用文件并显示需恢复，不出现部分改名成功的假象。
- “另存副本”使用当前名称作为默认文件名，通过任务 ID 与素材 ID 校验关联，仍由系统对话框选择路径和确认覆盖。不接受页面提供任意路径或文件名。
- 应用外部副本及其他软件自行记录的文件路径不自动同步。OpenChatCut 素材互通仍属暂缓范围，本轮不扩展剪辑接入。

## 4. 数据与接口约定

追加 SQLite v14，保持 v1–v13 SQL/checksum 不变并使用原备份/事务流程。`drafts`、`group_drafts` 增加 work_name；任务增加可空 work_name 与 work_name_revision。未改名任务的 NULL 回退不可变输入中的 workName，显式空字符串表示清空名称。老请求省略名称维持原规范输入与去重行为；旧草稿调用省略字段保留已有名称。

任务 HTTP、WS、历史投影统一新增 `workName`、`submittedWorkName`、`nameRevision`；改名增长任务 revision，迟到响应不得覆盖新名称。输入快照和本地提交意图允许可选 workName，不改写历史输入。

`POST /api/nova/storage/tasks/:id/name` 严格接收 `{requestId,expectedNameRevision,workName}`，返回任务 ID、名称版本、改名文件数及更新任务。相同 requestId 同操作复用，改变操作拒绝；名称版本防并发覆盖。使用现有 group_file_operations 日志，和归组/恢复操作互斥。任务和素材只接收稳定 ID，不接收路径、凭据或模型调用参数。

| N01 数据与查询 | naming_backend 子代理 | v14、草稿、输入冻结、任务投影、搜索、改名 HTTP/WS 接线 | 依赖 N00；旧库、幂等、草稿隔离、多词跨字段与 HTTP 回归 |

## 6. 验证范围与完成门槛

仅使用隔离数据库、假凭据、合成媒体、本地 loopback 服务；不读取真实用户库、不触发收费生成。覆盖旧库升级及旧输入重放、默认/分组/模式草稿、名称不出站、HTTP/WS 修订、搜索顺序与跨字段、全部输出改名、共享引用、冲突不覆盖、文件缺失/故障恢复、重命名后归组/重新下载、另存关联白名单。前端运行相关 Vitest、完整 TypeScript；后端运行存储/任务/媒体相关回归，主会话独立核查风险路径。
