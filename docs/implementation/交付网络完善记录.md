## 修改内容

- 新增共享发布网络层，使用同一 undici 包的 fetch 与 ProxyAgent，所有发布 API、二进制上传、下载校验使用相同显式代理配置。结束时关闭连接池。
- 支持 --proxy / NOVA_RELEASE_PROXY，--direct 覆盖环境代理。参数不接受代理用户名、密码、查询串。菜单可选代理；预览不联网。不自动读取系统代理、切换节点或改变 VPN 配置。
- API 总时限 60 秒，连接 30 秒，单个上传或下载校验总时限默认 1800 秒；60 秒无应用可观察进展停止。--transfer-timeout 和 --idle-timeout 可设为 1–7200 整数秒。下载重定向共用总时限。
- 每 5 秒显示字节数、耗时及平均速度。上传指标是交给传输层的字节，可能有缓冲，不表示服务器已收到；收到成功响应后仍需完整远端 SHA512 核验。API/HTTP 状态、总超时、停滞及连接失败分开报告，不输出原始远端异常、授权头或下载 URL。
- 同一次交付的草稿上传、补传检查、发布检查共享内存校验记录。每阶段重新获取远端身份与资产元数据；缓存绑定仓库、Release ID、源码、标签、资产 ID/名称/大小/状态/更新时间/摘要及本地 SHA512。元数据缺失或改变重新下载，进程重启后不复用。
- starter 失败占位先报明确错误，不下载该占位，也不自动删除。检查确属本次失败上传且草稿/源码/文件名一致后，由操作者清理该占位再续跑；uploaded、未知状态及已发布资产不得按占位删除。没有加入自动删除 API。
- 保留全部签名、固定仓库、源码绑定、版本及发布门槛。
