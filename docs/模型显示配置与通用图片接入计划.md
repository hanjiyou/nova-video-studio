## 需求与现状

用户确认设置页效果图与隐藏模型交互。上游模型目录读取成功不代表客户端已接入；现有图片链路在界面、任务校验、请求构造多处限定flare，sunburst虽可见但被拦。公开报价的旧“Image2原生-中质量”已不存在。本轮替代型号散落硬编码及旧固定报价规则，不扩大到自动生成/自动更换型号。

设计参考：[设置图](design/model-display/settings-reference.png)、[隐藏提示图](design/model-display/hidden-model-reference.png)（会话生成设计，已归档到项目；内置imagegen生成）。模型状态/数量是示意，实际界面必须来自数据。

## 最终行为

1. 请求当前连接模型目录，优先端点分类、保留手动分类，再按图片/视频分栏配置。配置控制生成页显示，隐藏不删除模型、任务、作品。
2. 图片初始选择flare、sunburst；视频沿用已开放型号。初始默认来自可用配置；上游后续新增型号默认未勾选。刷新、重启保留选择；供应商移除型号显示不可用且不能创建新任务，不静默换型。
3. 每类默认必须在勾选且已接入的型号内。全部隐藏可保存，对应默认为空、生成页提示前往设置。隐藏默认时要求明确设另一默认或全部清空，不悄悄替换。
4. 配置按连接/凭据身份隔离，cn/com线路共享显示偏好但保存检查线路revision；异步旧响应不能覆盖新连接或新配置。
5. 当前草稿型号被隐藏：收起的选择控件暂显示“型号 · 已隐藏”，下拉候选不含该型号；其下紧凑提示“当前模型已隐藏”“请选择其他模型，提示词和参考图会保留。”及“选择模型”操作。保留提示词、参考图和历史预览；不自动提交。重新选择后按正常校验恢复生成。其他型号隐藏不打扰当前草稿。
6. 图片生成按协议与集中配置匹配，flare/sunburst共用标准图片协议，实际model来自任务快照。未来同协议型号只改配置；未知协议不自动开放。旧任务adapter身份、快照与重试兼容。
7. sunburst允许用户主动提交文生图与单图参考，自动参数空对象也能提交；不因未有历史成功证据再次封锁。记录为用户授权可提交/未真实验收，不伪造成功验证。
8. 价格组支持精确“【生图分组】image2超分”“【生图分组】Image2-满参”。旧组失效迁移为空，明确请用户选择，不偷偷选最低价。基础价乘所选倍率显示单值参考价，支持当前型号；不改实际计费组、不查询Key分组。公开报价只初始化或模型刷新获取，不随勾选/普通读取反复请求。

## UI还原规范

- 保留实际侧栏、工作台主题与既有全部设置功能。设置页采用通用/连接与模型/存储/关于导航；不得只有装饰标签或丢失原功能。首次配置向导独立兼容。
- 连接与模型首屏层级：页标题/导航 → 紧凑连接栏 → 模型显示标题和两行说明 → 图片/视频双列卡片 → 报价组紧凑配置/分类管理 → 保存操作区。
- 深石墨底、细灰紫边框、约12px圆角、紫色勾选与主按钮。主区域24–32px内边距，卡间16–24px；标题与表格对齐。禁止额外拼接效果图式说明区域。
- 连接栏展示真实连接名称/状态、线路和刷新。线路修改复用现有受控保存流程，不只改变标签。
- 双列等宽卡片：图标标题与已显示数量、搜索框、列表表头、型号行、默认操作。行高约56–64px，完整型号可换行；复选框视觉约20px且点击区至少32px。不要用一长串正文代替表格。
- “可提交”表示已接入且策略开放，不声称真实验收通过；未开放/未接入/上游不可用有明确原因。搜索不改变选择，统计不随搜索误变。
- 取消更改恢复最后保存快照；保存成功后生成页立即一致。保存失败保留本次输入；刷新列表保留未保存勾选。按钮loading/disabled/键盘focus可见，状态提示可被读屏读取。
- 小屏双列转单列，长型号与操作不横向溢出；不压缩成难以点击的控件。桌面1536/1280及窄屏390检查。
- 报价组不在原图中，但为已授权失效修复，放在模型卡片下方紧凑区域，不混入模型状态，也不展示假报价。

## 接口与持久化

复用app_settings，不改既有迁移。models返回displaySettings：revision、imageModels、videoModels、defaultImageModel、defaultVideoModel、pricingGroup；每项模型增加submissionEnabled（由真实配置计算）。

新增GET/PUT /api/nova/connections/:id/model-display。PUT原子提交connectionVersionId、expectedRouteRevision、expectedRevision和全部配置字段。并发冲突返回清晰错误，不覆盖别处新修改。读取不隐式重置显式空列表。首次默认与以后新增必须区分。

新任务在幂等查重后、模型目录确认后检查显示政策；已创建任务、重放/历史下载重试不受后来隐藏影响。客户端检查不代替后端新任务检查。

报价读取支持model参数，固定允许的分组值，失败保留明确不可用状态；保留原路由、凭据身份、迟到响应隔离。
