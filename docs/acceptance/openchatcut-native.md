## Nova连接与可靠性

| ID | 场景 | 验收结果要求 |
| --- | --- | --- |
| B01 | 作品库选择混合正式输出 | 顺序不变、缺失明确、原图视频不修改；同请求同快照复用 |
| B02 | 原件归组/隐藏/删除 | 原版已有可靠副本的工程继续可编辑；传输中引用不被清理 |
| B03 | 工程与剧本关联 | 稳定ID、重启可恢复、归档/删除冲突明确，不偷偷改生成历史 |
| B04 | 两条导出路径回库 | 原版导出与Nova保存事实分开，入库前不宣称完成 |
| B05 | 回库失败/重复通知 | 可单独重试保存，无重复渲染、无重复本地作品、无云生成POST |
| B06 | 大于100MiB的成片 | 流式校验、播放Range和另存；不改变原生成/下载限额 |
| B07 | 数据/凭据隔离 | 不接触真实用户配置；正式凭据经safeStorage；无页面/工程/日志泄漏 |
| B08 | 来源与生命周期 | 独立session、越源导航/新窗口拒绝、非法IPC/viewport拒绝、并发open无重复服务 |
| B09 | 迟到/退出/更新 | 导航离开不迟到显示；编辑状态关闭/更新收尾；服务异常可重试 |
| B10 | 发布构建与安装升级 | 固定gitlink、子模块初始化、资源声明、旧资料保留、安装态实际功能 |

证据登记采用：源码核对 / 离线测试 / 原版真实运行 / Nova真实承载 / 真实媒体导出 / 安装态 / 真实云调用。未执行项保持待验证，不能汇总为全量通过。
