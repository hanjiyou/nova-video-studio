# 剧本分组与作品整理使用说明

适用范围：本轮开发源码；未提交、打包或发布。完整审核结果以专项实施记录和总任务台账为准。

## 开始一个剧本

图片生成、视频生成页共享“所属剧本”。没有指定时属于“未分组”。在“管理分组”中新建剧本，然后在生成页选择它。每个剧本、每种生成模式分别保存草稿；切换前会等待当前草稿保存，失败时保留原剧本和输入。将作品作为参考图只添加到当前目标草稿，不自动改成原作品所属剧本。

新任务按当前保存根目录写入，例如：

~~~text
D:\LocalAICG\NovaStudioOutput\
  assets\
    未分组\
      图片\
      视频\
    海边短片\
      图片\
      视频\
        20261027-143200_海边嬉水_稳定短编号.mp4
~~~

文件名使用任务创建时间、简短提示词和防重编号；不为命名调用生成接口。中文、空格、括号和&可以使用。Windows保留名、路径分隔符、末尾点或空格等会被明确拒绝。目录与文件路径过长时会在提交生成前检查并提示。

改保存根目录只影响新任务。历史任务仍在原根目录；修改历史任务所属剧本时，也在它原来的根目录内整理。界面展示实际位置，可以用“打开结果目录”定位。config、logs只预留未来用途，本轮不会移动数据库、凭据或日志。

## 找作品和找任务

作品库只展示曾完整下载、校验、保存并关联成功的图片、视频。左侧选择全部作品、未分组或某个剧本；保留类型和关键词过滤。这里不再提供任务状态过滤。

双击卡片或用键盘打开图片/视频预览，视频可播放、拖动进度和全屏。底部“任务详情”查看完整提示词、时限、错误、历史生成事实与保存位置。卡片封面可能裁切，预览窗口完整展示原图；不会裁改原文件。多输出暂按一条任务卡片管理，预览沿用首输出，卡片标明输出数量。

生成中、下载失败、超时或需要人工处理的任务，到生成页的最近任务或“查看全部任务”中查找。最近视频数量在设置里调整，默认6条、允许1–100；图片仍显示最近6条。列表按任务创建时间倒序，完成、重下或改组不会把旧任务挤到最前面。

曾保存成功的文件后来缺失或损坏，作品库保留异常记录。首次下载失败的任务，只有重新下载并完整保存成功后才进入作品库。手动重新下载获取原结果，不创建新的生成任务，也不宣称支持字节断点续传。

## 修改归组和管理分组

作品卡片可单项拖到另一个剧本，也可从菜单修改分组；全部作品只是聚合视图，不能作为投放目标。拖回原分组不做移动。一次移动覆盖该任务所有正式输出，不能把同一任务的不同输出分到不同剧本。

正在生成、下载或仍在收尾写文件时不能改组。没有成品的终止任务可从全部任务或任务详情修改归属。改组不会重新生成。文件移动失败会显示原因；原始输入、共享引用和用户原件受到保护。中断需要恢复时先解除文件占用或恢复目录，再使用恢复入口；不会通过重新生成弥补文件问题。

重命名剧本会同步它在已登记根目录中的受管位置；有活动任务或待核对提交意图时暂不允许。归档保留历史与文件，取消归档后可继续提交。只允许删除没有任务、作品或有效草稿、且目录为空的自建分组。“未分组”不能重命名、归档或删除。

## 整理升级前的历史文件

原来的 assets/d5/摘要.mp4 等文件升级后仍可读取，逻辑归入未分组，不会自动移动。使用“整理历史文件”先查看范围、源位置、目标位置和冲突，选定后再执行。每条任务单独报告成功或失败；不是一次全盘扫描或自动迁移。

从作品库隐藏记录、从任务列表移除、删除文件是不同操作。以实际弹窗说明为准；涉及文件删除时仍保留共享文件、输入参考图和其他引用，不将普通归组或归档变成删除文件。
