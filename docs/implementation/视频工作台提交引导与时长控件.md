## 实现行为

### V01 紧凑默认时长

时长 number 输入与次级“设为默认”按钮同为 44px 高，独立布局避免被原两列网格拉伸；窄屏允许换行。旁边显示当前连接、型号有效的“默认 N 秒”，数值沿用 videoDefaults 的已保存配置及既有规则兜底。

当前输入等于有效默认时显示勾号及“已设为默认”；修改本次秒数只改草稿，不自动保存默认。保存中通过同步 busy 标记与禁用状态防重复；仅在成功回执的连接/线路与所选型号 defaultSeconds 均精确匹配后确认成功，缺少保存字段不能把规则兜底当作成功。失败可重试，不提前改变默认。

小组件 VideoDurationControl 由 DraftEditor 按连接标识、版本、服务身份、线路修订和完整型号作为 key 隔离。切换后原组件卸载，忽略旧请求的成功、失败与最终状态，不调用当前页面的 onModels，也不污染当前默认文案。既有视频秒数范围、参数默认规则、价格和能力门槛保持。

### V02 同一条件来源与可执行入口

generationPlan 增加结构化 issues，并令 blocked 仍为首项 message，兼容现有提交钩子。连接/型号可见性/能力证据、空描述、参考图数量和缺损、图片规格与视频参数均由同一校验生成原因。只有匹配能力存在时才判断派生参数不符，避免“没有 capability”时编造历史规格错误。

单图必须 1 张；多图 2–7 张，0 张明确还需添加 2 张、1 张明确还需添加 1 张。空描述与缺图会同时列出；数量足够也仍须满足原有能力门槛。超量或损坏不自动移除。旧文生视频草稿若残留参考图，会展示原图与移除入口，允许明确修正原有禁用条件。

DraftEditor 将 issues 与草稿保存/保存失败、导入、建立任务、父级禁用及缺少提交入口等运行条件合并。该列表同时决定实际生成按钮禁用与 footer 中可见的温和高对比提示，不依赖 tooltip。保存/导入/提交忙态显示等待说明，隐藏修改入口；配置连接是导航入口，保持原有可用性，不因草稿自动保存而禁用。

| 原因 | 文字按钮执行的动作 |
| --- | --- |
| 缺少参考图 | 添加参考图 / 继续添加，复用现有桌面导入或隐藏文件选择器 |
| 描述为空 | 去填写，滚动并聚焦实际 textarea |
| 时长无效 | 调整时长，滚动并聚焦 number 输入 |
| 规格/尺寸待调整 | 核对参数，定位参数区域 |
| 素材缺损或超量 | 查看参考图，定位保留的原参考区，由用户明确处理 |
| 连接不可用 | 配置连接，调用现有 onConfigure |
| 型号或能力问题 | 检查型号，定位型号选择 |
| 草稿保存失败 | 查看保存问题，定位原保存错误和重试入口 |

父组件 WorkbenchShell 从真实状态构造 SubmitBlocker，并从该数组派生 submitDisabled：提交记录尚未核对、当前草稿已提交、未解决提交意图、更新冻结分别说明。核对操作复用 reconcile/refresh；准备新任务复用 allowAnother；更新安装仍由原有 inert 和更新屏障保护。旧调用只传 submitDisabled 时有明确兜底原因。

添加、填写、核对、准备新任务和默认值保存均不会自动调用 onSubmit。实际生成按钮仍需用户明确点击，提交钩子的原有去重与恢复保护继续存在。
