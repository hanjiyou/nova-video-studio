# 图片参数与单图编辑：离线实现与验证

日期：2026-10-24。仅本地开发与离线验证；不读真实 Key、不调用真实生成服务、不生成安装器、不提交或发布。原 T16 外部接收结果、现有多图视频扩展和用户数据保持原记录。

## 范围与协议

- 保留无参考图、自动规格的原最小生图请求 `{model,prompt,n:1}` 及已验证能力 UUID。
- 显式 size/quality 与单图参考编辑各有独立不可变能力记录；仅精确 OpenSosen 线路允许用户主动提交，仍为 unverified。官方 Image API 文档是标准协议依据，不能证明此中转支持全部参数。
- 尺寸为 1024x1024（1:1）、1536x1024（3:2）、1024x1536（2:3）；质量为自动、low、medium、high、xhigh、max。自动省略对应字段，不把 auto 字符串强塞入旧最小请求。
- 单图编辑固定 POST `/images/edits`，multipart 字段为 model、prompt、n=1、显式 size/quality，以及一个 image 文件部件。受管资产提供真实 PNG/JPEG 字节，由运行时生成 boundary；不重编码、不压缩、不猜别名或自动换字段重发。
- 图片适配器 1.1.0 精确兼容旧 1.0.0 最小图片任务。相同本地意图返回原任务；不同输入冲突。已派发无明确结果的任务保持 submission_unknown 与唯一占位，重启不会重发。
- 结果继续走原媒体校验与安全下载。预览、另存、定位保留；新增“作为参考图编辑”和作品库单选带入图片草稿，通过现有草稿替换对话框，不自动生成。

官方依据（2026-10-24 主会话读取）：[Image generation guide](https://developers.openai.com/api/docs/guides/image-generation)、[Edit image API](https://developers.openai.com/api/reference/resources/images/methods/edit)。一般单图沿用 image 字段；官方多图示例 image[] 未在本轮开放。
