## 宿主与安全

- `validateAndSaveConnection` 只接保存字段、UUID `operationId` 和可选引导 revision。Key 仅在表单与宿主本次检查期间存在，复用原只读 `GET {canonicalBaseUrl}/models`、8 秒/1 MiB/5000 条预算、禁止重定向及固定安全错误。检查失败不创建连接/凭据；200 空列表可保存为只读检查成功，但目标型号缺失仍不可用。
- 编辑/取消/离开表单向宿主作废 operationId；较新检查、另行保存、清除、默认项完成都会作废旧候选。在成功写事务前再次核对宿主操作身份和当前连接版本；旧响应晚到不能写入或切换连接。即使测试传输故意忽略 AbortSignal，宿主闸门仍生效。
- 已保存配置未修改时，可由宿主读取原版本凭据做检查，不向 renderer 返回 Key；失败只更新该版本检查健康状态并保留旧模型缓存。新 Key/地址失败不会污染原配置。未更改配置的检查不新建连接版本。
- 成功检查的连接/密文、模型缓存和引导 `defaults` 步骤在同一事务落盘；`completeWorkbenchSetup` 在目录复查后原子保存用户确认的默认型号与引导完成状态。更改默认型号产生新版本，旧任务、旧凭据/路径绑定不变。
- Key 保存完成即清空，离页或 Esc 恢复遮挡；取消/失败可继续编辑与重试。原文及两轮百分号编码 Key 不得进入名称、地址或型号。没有浏览器持久 Key、旧 exe/data/browser 探测、日志原始响应或付费探测。
- 清除 Key 前说明会撤销该连接所有版本、暂停需要鉴权的旧任务，远端可能继续生成/计费；任务与素材保留，旧损坏或清除版本不改绑新 Key。模型列表不支持、401/403、离线、格式错误、未验证及缓存过期分别说明；模型可见性不升级生成能力证据。
- 输出目录沿用系统选择与真实写入探测，完成默认项前再探测当前目录；失效/不可写会阻止完成，不搬旧文件。只暴露受控目录名称和 opaque 引用，不接受 renderer 任意路径。
- 顶层数据目录 mkdir 纳入启动捕获；初始化及后台启动错误使用原生可见提示，只输出固定错误代码，不回显原始异常、路径或凭据。
