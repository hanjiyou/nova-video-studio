## 主审发现与修复

1. 同一视频快速离开重入时，旧play回执曾可能暂停更新轮次；现以播放轮次/所有权隔离，交错resolve回归通过。
2. 午夜遇活动批次，重设定时器可能漏更新当天边界；现采用同一tick重试及批次结束补日，活动批次跨午夜回归通过。
3. 首项等待阶段未立即显示本批0/N，可能暂留旧批进度；现开始即初始化本次进度。
4. 批量后最后一页失效时，自动纠页曾清除失败选择；现与用户切页区分，并保留失败快照重试。对应部分失败/自动纠页用例通过。
5. IntersectionObserver首回调前所有视频曾带src；现初始不附着，由视口确认后加载。失焦/hidden不只停止一次，新增门闩阻止新hover启动。
6. 跨年/历史范围标签补年份及完整title，窄屏不溢出。
7. 原生鼠标补测早期未触发dragstart，一度怀疑无src视频；最小标准draggable DIV也同样失败后，撤回该归因及无依据的业务试改，保留输入链限制证据。不能把程序派发DragEvent通过算作原生鼠标验收。
