## 实现

- `WorkbenchLibrary.tsx`：卡片鼠标单击不再打开详情；双击封面 / 内容区打开独立预览，聚焦后 Enter / Space 同样可用。新增卡片“任务详情”按钮，沿用原 `onDetails`。选图、移除位于独立操作区，不触发预览。
- `WorkbenchLibraryPreview.tsx`：只读取首个输出的受管 `previewUrl`，图片 contain，视频使用原生 controls，不自动播放。复用 `WorkbenchDialog` 和 `AssetActions` 的另存副本、打开结果目录；不改公共弹窗、任务详情或后端。
- X / Esc / 遮罩关闭均卸载预览。播放器清理调用 pause、移除 src 并 load 释放资源；effect setup 恢复同一受管源，兼容 React StrictMode 的 setup / cleanup 重放。
- 无输出、生成未保存、下载失败、缺失 / 损坏及无预览地址显示明确中文原因。实际图片 error / 视频 error 会移除失败媒体，显示提示，保留独立任务详情恢复入口，不自动生成或重新下载。
- 筛选、页码和图片选择顺序继续由原作品库维护，弹窗关闭不会重置。原类型 / 状态下拉、分页、删除语义、首输出规则和最近 6 个规则保持。
- `globals.css` 末尾仅追加预览 contain、宽度 / 高度限制、换行与提示样式；卡片操作继续使用现有 flex-wrap。
