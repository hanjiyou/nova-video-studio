## 边界决策

1. upstream completed只是remote_completed，必须下载、验证并原子落盘后才能本地completed。mock默认下载是任意字节，不能作为合法MP4或本地完成证明。
2. 停止查询保留ID且可能继续远端执行；不等于远端取消，不虚构取消端点或退款。
3. localRequestId是持久化本地去重标识，不代表上游幂等。mock故意不按Idempotency-Key去重，使重复创建可以被计数发现。
4. after_accept/超时/断流测试明确断言submitPosts=1、acceptedCreates=1，证明测试服务能制造“已接收但客户端失败”的情形。fetch失败不能证明POST未发送。
5. GET使用有界退避、次数/累计预算及暂停策略；有效Retry-After超出等待预算时暂停并保存notBeforeAt，不截短后提前查询。POST429绝不落入GET自动重试策略。
6. 输出目录版本/根引用纳入不可变任务快照，实际路径只由宿主解析，目录变更只影响新任务。
7. FormData将普通文本字段的行结束符规范为CRLF；快照保留原文，测试只处理标准换行表示，不trim或折叠空白。文件仍严格逐字节。
