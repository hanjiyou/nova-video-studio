## 本轮行为

图片型号仅支持精确的 gpt-image-2.5-flare。单张估价为公开基础价 model_price × enable_groups 中每个分组的 group_ratio，再显示最小到最大数字。本次固定 1 张，不推断 Key 所属分组，不做币种换算，不显示币种符号。

合成资料基础价 1、倍率 0.05/0.12/0.4 时显示 0.05–0.4；只有 0.12 分组时为 0.12。基础价变为 2 时区间为 0.1–0.8。小数估价保留合理精度，例如 0.1 × 0.05 显示 0.005，并隐藏浮点计算尾数。0 为有效价格。

费用区域提示“按可用分组估算，实际以所属分组结算；尺寸和质量不影响本模型估价”。尺寸和质量变化不改变估价、不触发新的价格读取；原能力证据和未实测提示保留。视频继续按原配置每秒单价估算。

## 实现边界

- 新增受保护的 GET /api/nova/connections/:id/pricing；沿用本地会话保护，其他方法拒绝。
- 仅现有 route-policy 精确内置 OpenSosen 连接支持；以所选 cn/com 的固定 HTTPS origin 读取 /api/pricing，不带 /v1 前缀，不开放任意主机。
- 匿名上游 GET 不读取凭据、不调用 getAuth，不发送 Authorization 或本地会话头；使用 redirect:manual，不跟随重定向；只接受 HTTP 200，并拒绝显式 success:false。
- 解析器只接受 quota_type=1、有限非负 model_price，以及确认的固定按张表达式。表达式仅作严格字符串识别，fixed 数字须与基础价一致，不执行表达式。未知计费方式、重复型号、缺失或异常的任一启用分组倍率都返回无法估算，不省略异常分组来缩窄区间。
- 上游读取总预算 8 秒，最多 1 MiB；两条公开源各保留一个内存槽，成功缓存 10 分钟，失败退避 30 秒，在途请求合并，无轮询、数据库迁移或新框架。
- DTO 仅投影型号、估价、简短原因、连接版本及线路版本等必要字段。旧版本或旧线路回执标 stale 且不附报价；前端同步隐藏旧型号/线路价格并忽略迟到回执和卸载后结果。
- 价格失败独立于连接验证、模型清单和生成按钮；显示“暂无法估算”与短原因，可手动重试，不用 0 代替失败。

本轮新增 image-pricing.js、ImagePrice.tsx 及两份专用测试，最小接入 service.js、http.js、connection-client.ts、DraftEditor.tsx。service.js 与 connection-client.ts 中既有线路改动原样保留。未修改旧 HTTP 测试夹具、共享约定、契约和总台账。
