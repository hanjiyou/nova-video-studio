## 解释与剩余验证

- Task diagnosticWriteFailuresThisSession 只反映当前进程已观察到的失败，不证明前一会话日志完整；丢失日志不能反推成功。更新 journal health 分别提供当前/可持久历史写入失败及本次读取状态。
- 日志能定位卡在哪个可观察环节，以及安全错误类型；不能保证知道外部服务内部原因、VPN 状态或父进程退出后的安装器行为。新版本启动与 window_loaded 分开；也不能证明版本由自动安装而非手动安装得到。
- installed 3.6.2 的启动安装逻辑仍是旧代码。把修复写进下一版不能改变 3.6.2 启动下一安装器的方式；应先手动安装含补丁的 A 包，再用之后的 B 包验证完整自动安装/重启/资料保留。当前批次未打包发布，B 电脑不会自动获得这些改动。
- 原 schema 不迁移；历史任务缺失字段为未知，旧安装过程无法补录。
