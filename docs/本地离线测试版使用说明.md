# Nova Studio 3.4.0 本地离线测试版使用说明

**四种基础生成模式已实测，完整功能仍在验收。本包仅供本地/受控离线安装测试，不能视为 61 项功能最终验收通过。** 精确原 OpenSosen 服务的 flare 最小文生图，以及 1.5 六秒文生、单参考、双参考视频已在本应用真实生成并开放。图片编辑/比例/尺寸/质量、普通视频型号及其他服务组合仍按能力记录门控。文生视频不传尺寸或图片，分辨率由服务决定；此次实测 1280×720 不代表未来保证。单/双参考固定六秒、1280×720；双图不等于首尾帧锁定。本包没有本地生成模型。

## 安装与启动

本批本地安装包为 `release-t16-followup/Nova-Studio-3.4.0.17-offline-test-x64.exe`，安装身份为 `com.novaimage.studio.offline-test.followup-20261024`，程序为 `Nova Studio T16 Followup.exe`，内部应用版本 3.4.0、安装包 Windows 文件版本 3.4.0.17（应用 EXE 因未编辑资源，保留 Electron 43.4.0 的文件版本）。它使用独立安装注册，不创建桌面/开始菜单快捷方式。选择当前用户可写目录安装；不要将配置或作品存入安装目录。安装结束后手动启动所选目录内的程序。

安装包自带 Electron/Node、SQLite 和固定 FFmpeg；正常使用无需安装 Node、npm、Python、浏览器插件或另一个 FFmpeg。当前机器存在开发工具，因此 PATH 清理后的成功测试只能说明不依赖 PATH 中的开发工具；现有受限标准令牌下安装进程退出 0、文件落盘，但未观察到卸载注册；启动时子进程返回 0xc0000135（DLL/运行时加载失败），尚未确定具体 DLL。同账户官方 Electron 最小窗口也失败，不能据此归因显卡。Administrator 当前用户安装、注册与运行已通过。普通用户完整运行、无开发环境独立机器与人工系统交互尚未通过，详见 T16 报告。未签名包没有自动更新；不为测试关闭系统安全设置。

## 无连接也能使用的部分

首次启动可点“暂不配置”进入工作台，分别编辑图片、视频文生/单图/双图草稿并自动保存。可导入 PNG/JPEG，导入后原文件另有副本；移除草稿图片不会删除源文件。作品库初始为空；测试样本只存在隔离验收 profile，正常启动不会出现演示结果。

图片、视频、作品库、设置四页共用本地数据。已有文件可离线预览，常见 MP4 可播放、暂停、跳转、调音量和全屏。本次安装验收复用已经生成的真实图片和三段六秒视频，不增加收费生成。普通用户或另一台电脑的结果需按独立验收步骤实际验证。

设置里的连接检查只检查鉴权/模型列表，不生成作品；“连接成功”不等于某型号全部模式可用。Key 通过 Windows 系统保护加密落盘，不要把真实 Key 放到截图或反馈中。本轮安装测试没有读真实 Key、调用真实连接检查或付费生成。

## 数据、升级和卸载

默认数据目录是 `%APPDATA%\nova-image`，包含 SQLite、加密配置、草稿、受管素材和默认输出。自定义输出根只影响新任务；旧任务继续使用原目录版本。已有用户资料必须保留，不要删除此前留存的目录。

如需隔离本地测试，从 PowerShell 设置一个**全新且不在安装目录内**的目录后启动：

```powershell
$env:NOVA_DATA_DIR = 'D:\Nova测试资料\独立配置'
& 'D:\Nova测试安装\Nova Studio T16 Followup.exe'
```

该覆盖只对启动它的进程及子进程生效，测试后可关闭 PowerShell。不要在同一 profile 同时运行不同版本。应用单实例锁按 profile 隔离。

升级前关闭应用并备份整个数据目录和自定义输出。安装同身份后续包会替换程序；本轮用独立测试身份的旧 ASAR→新 ASAR、同应用版本覆盖验证程序更新路径；不等同正式发布身份跨版本或未来 schema 迁移测试。数据库实际发生 schema 升级时在迁移前备份；不要手动编辑数据库。

卸载移除安装目录及其程序文件，保留安装目录外的 profile 和作品。安装程序显式禁止 `--delete-app-data`。不要把数据放在安装目录内；卸载会移除整个安装目录。重新安装后使用同一用户/同一覆盖目录可恢复数据；加密 Key 不能保证跨 Windows 用户或跨机器复用。没有自动寻找/导入旧 Nova exe、相邻 data 或浏览器资料。

## 任务与文件

正常启用真实能力后，提交先保存本地快照；远端可能已接收但回执不明时显示“提交结果待核对”，不会自动重发创建。停止查询只暂停本地查询，远端可能仍在生成或计费；它继续保留单生成占位，后续队列等待同一任务明确终态。

重启后未派发队列等待明确继续；有 ID 的恢复只查询原 ID。下载失败可重试下载，不能通过新建生成找回文件。修改连接、默认型号或输出目录不会改变旧任务。保存按钮实际是“另存副本”；取消正常，重名由系统对话框确认。文件外部缺失时保留任务记录。

## 诊断和反馈

设置→“导出脱敏诊断”→选择安装/数据/受管输出之外的目标，生成本地 JSON，不上传。包含版本、状态、已知参数、资产摘要等；不包含 Key、提示词原文、路径、服务/资源 URL、原图、原始响应或完整日志。导出目标受保护，取消不算错误。应用打不开时记录可见启动错误并保留数据，不先删目录。

反馈建议附应用版本、操作步骤、脱敏诊断以及是否更换目录/账户。不要提供真实 Key。系统文件对话框、资源管理器的人工完整交互和标题栏拖动仍须人工验收。
