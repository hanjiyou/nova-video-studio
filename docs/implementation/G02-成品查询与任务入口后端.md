追加schema v13的tasks.saved_at作为不可擦除的曾完整保存事实。迁移仅从正式输出关联及可信完成记录登记（完成下载、成功尝试、已完成本地保存或无下载行的旧completed记录），不根据磁盘当前有文件猜测。原结果保存事务完成后登记；旧completed任务后登记历史成品有窄兼容触发器。首次下载失败后的成功重下可登记，即使首次localOutcome仍为failed；后续重新下载失败不会擦除保存事实。

GET `/api/nova/storage/tasks`支持scope=library/workbench、groupId及category=active/unfinished/completed（省略为全部），保留kind/search/model/status/limit/offset。全部条件在SQL分页和count之前组合。按created_at DESC,id DESC稳定排序，更新、重下、归组不按更新时间置顶。

library要求正式output关联+saved_at，排除临时文件、下载检查点、远端completed和无输出任务；缺失/损坏保存记录仍可见。仅library过滤workbench_hidden_tasks；workbench仅过滤workbench_removed_tasks。作品库隐藏不再让全部任务失去旧失败入口，任务移除继续保留成品。组workCount/taskCount共用同一谓词。

类别：有效下载尝试优先active；不需人工继续且正在排队/提交/生成/下载的未终止任务active；无活动尝试但有保存事实的记录completed。其余unfinished，明确覆盖submission_unknown、polling_paused、重启requiresContinue、失败/取消/超时和未知旧状态。缺失保存文件仍保留completed事实及异常提示，重下活动时任务类别优先active，作品库仍保留原记录。DTO增加savedAt/taskCategory。
