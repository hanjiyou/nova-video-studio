## 本阶段交付

- [桌面运行/API说明](../desktop-runtime.md)与 desktop/runtime.cjs：在 SQLite/队列启动前获取单实例锁；安装版默认系统 userData，保留 NOVA_DATA_DIR 和便携目录优先级；回环端口冲突有界选择。
- desktop/network.cjs：默认直连，可选择系统代理或仅 GET/HEAD 的有限回退；生成 POST 只发一次，写请求及内部请求禁止自动跟随重定向。中断提供 SUBMISSION_UNKNOWN 传输分类；未提前实现 T05 持久任务状态机。
- backend/desktop-session.js、desktop/session-policy.cjs：主进程随机会话保存在内存，HTTP/WS 同时校验回环/Host/Origin/会话，包含无 Origin 的外部客户端；Electron 要求正确 webContents 和实际主 frame 才注入头，其他请求剥离该头。
- desktop/ipc.cjs 与 preload：公开运行信息、系统目录选择和 UUID 资产操作入口；目录 realpath/写探针验证后只给页面不透明选择ID，宿主保存真实路径。另存/定位资产明确返回 ASSET_SERVICE_NOT_READY，等待 T03/T08；不把尚未实现的文件服务报为成功。
- 桌面主文档 CSP 禁 worker/frame，关闭 PWA 注册与默认 Agent/CDP/自动启动后台能力。启动清理只针对应用 origin 的 serviceworkers/cachestorage；Web Agent、PWA 和旧图片流式兼容回退保留。React 使用与 SSR 一致的 hydration snapshot，功能确认前不挂载 Agent，也不初始化其会话存储。
- 退出撤销会话、取消等待中的请求，关闭 HTTP/WS/定时器/IPC、checkpoint 并关闭 SQLite；打包清单包含新增后端模块。

没有新增依赖、升级锁文件、读取真实 API Key、调用付费生成服务，未做 T03 数据迁移、T04 凭据持久化、T05 恢复状态机或 T09 四页改版。T01 最终提交已由主会话接受，任务清单据此同步 T01/M0 已验收；T02 保持待审查。

## 重要失败与修正

1. **真实Worker越权**：[首次失败](t02-evidence/native-worker-attribution-failure.json)中 blob Worker 的真实API fetch返回200。Chromium把该请求归因到所属主frame，说明只校验details.frame仍不足。经主会话认可，桌面主文档增加worker-src/frame-src none；复验要求浏览器实际CSP违反事件而非仅看代码。修复后的主HTTP/WS、重载和Web分支一起通过。[异步阻断测试初轮](t02-evidence/native-csp-async-worker-test-failure.json)还记录了CSP异步error而非构造同步抛错，测试据实修正。
2. **App Router Web PWA**：[初轮Web注册超时](t02-evidence/native-web-pwa-failure.json)。next-pwa的Workbox全局注入只挂旧main.js，当前App Router页面可能没有该全局。运行期Web分支在无Workbox时显式调用原生register('/sw.js')；桌面始终返回。真实Web重新注册通过。
3. **NSIS首次安装收尾崩溃，原因仍未确定**：[首次记录](t02-evidence/installer-finalization-first-failure.json)。2026-10-23约15:24，本次静默安装已经复制程序、资源和卸载器，在收尾阶段进程返回 -1073740791；[Windows Application Error 1000原始记录](t02-evidence/installer-windows-event.json)记录异常0xc0000409、模块ntdll.dll，故障应用为本T02安装器。应用文件可实际启动，system/override/portable均通过。首次卸载器退出0并移除测试exe；使用**相同SHA-256包、相同目标目录**重新安装退出0，重装后的应用再启动退出0，最终卸载也退出0。未发现残留运行进程；本阶段没有证据将原生崩溃归因到某个应用改动，**一次重试通过不代表问题已解决**。是否阻塞T02由主会话审阅，安装可靠性在T16仍需复核，不无依据循环重装。
4. 初轮新增单元测试遇到Windows同步/异步realpath短名差异、Node fetch不允许伪造Host；改用同一异步realpath及真实原始HTTP请求。初轮构建的重复声明来自CRLF编辑替换遗漏，修正后TypeScript/构建通过。新增PWA测试的afterEach先恢复navigator再卸载组件导致1个清理失败，[原日志保留](t02-evidence/frontend-regression-first-test-cleanup-failure.log)，显式先cleanup后完整676项通过。后端原有2处空catch与字面BOM正则的lint错误只做等价注释/转义修正。打包CLI的短参数被解析为配置文件名，[原失败日志](t02-evidence/packaging-first-cli-failure.log)保留；改用显式临时配置后构建通过。
