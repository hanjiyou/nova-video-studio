# Nova Studio 本地剪辑预览包

> 2026-11-02发布后状态：GitHub Test 3.6.11已提交、推送、独立构建并公开发布，包含剪辑基础入口、参考图粘贴和保存提示优化。素材/工程/成片进一步融合继续暂缓，未验证能力与正式签名/安装升级门槛保持；旧local.1/local.2不变。以下“仅源码/未打包/3.6.10基线”均为发布前阶段记录，当前以[3.6.11交付记录](implementation/3.6.11-交付记录.md)为准。

> 2026-11-02 当前包：现有最新本地剪辑预览版本为3.6.11-local.2，local.1保留；[包与入口](implementation/OpenChatCut-本地预览包.md)可查。与Nova的素材/工程/成片进一步融合按用户决定暂缓，不把这些未实现项视作完整接入。当前本地包不含11月2日新完成的参考图粘贴与草稿保存提示优化；它们仍仅在开发源码中。

本包用于预览首批 OpenChatCut 接入，具体版本见应用设置及本批 build-summary.json。未签名，仅保留在本机，不提供自动更新。

双击安装包可安装为 **Nova Studio Editor Preview**。请使用它默认的独立安装目录，不要选择已有 Nova 的安装目录。也可直接运行同批 `win-unpacked/Nova Studio Editor Preview.exe`，无需安装。不要只复制其中的 exe，必须保留整个 win-unpacked 文件夹。

首次启动使用独立资料目录 `%APPDATA%\Nova Studio Editor Preview`；不会自动读取已有 Nova 的连接、密钥、作品和工程。若启动环境显式设置了 NOVA_DATA_DIR，该覆盖设置仍优先，请用新的测试目录。

首次配置页可进入本地视频剪辑，或跳过配置后点击左侧“视频剪辑”。首次加载原版资源需要稍等。

本批可查看原版 Agent、资源面板、预览、时间线与六个主页签，切页及关闭重开空工程已验证。可尝试原版选择本地素材的入口；真实媒体制作、完整导出与长视频仍未完成验收。

作品库送入剪辑、剪辑成片回作品库尚未接通。Agent 聊天界面保留，模型密钥、联网音频搜索、本地转写与外部工具配置尚未接通；凭据写入暂时被明确拒绝。

3.6.11-local.2起，Nova和剪辑共用包内同一份通用FFmpeg（Remotion另有不同的渲染版本，仍保留），无需手动配置。无需另装 Node/npm，也不依赖开发仓库。应用、原版界面与本地服务随包提供。模型下载和服务端渲染所需的完整依赖仍待后续接入，不表示 OpenChatCut 全部功能已可用。

退出前等待原版保存完成。反馈请附操作步骤及错误提示，不要发送真实 API Key。许可文件随 resources/licenses 及 resources/openchatcut 内依赖提供。该本地预览不代表正式安装、升级或完整功能验收通过。
