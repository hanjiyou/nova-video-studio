## 读取及刷新语义

| 触发 | 行为 |
| --- | --- |
| 某连接版本、线路及修订首次 GET pricing | 初始化一次匿名公开报价；同 scope 的在途读取合并 |
| 页面重挂载、再读 pricing、参数变化或单纯时间流逝 | 读取同 scope 已有缓存；无 TTL 到期自动外呼 |
| checkConnection 进入实际模型网络刷新 | 与模型请求并发强制更新一次报价；成功/失败均更新价格快照 |
| checkConnection 使用模型成功缓存或失败退避 | 不强制刷新价格；首次 pricing GET 仍可初始化缺失的 scope |
| 完全未改字段、Key、线路的已有连接“保存并验证” | 在既有模型 probe 旁并发更新当前报价；保留原 operation 及冲突检查 |
| 新建或修改候选连接 | 不向未保存候选挂价格缓存；保存后首次 pricing GET 初始化实际版本 |
| 换 Key、连接版本或线路修订；切回同源的新线路修订 | 新 scope 首次读取；不借用旧版本或旧修订报价 |

缓存按 connectionVersionId + route + revision 隔离，最多 64 个槽；只淘汰已结束的旧槽，不淘汰在途合并工作。进程重启或旧槽被淘汰后，下一次访问会重新初始化。没有常驻轮询、后台定时刷新、数据库迁移或新框架。

强制刷新先撤下旧成功值；普通 GET 在刷新期间等待同一在途结果。失败会缓存明确不可用，直到实际模型刷新或新 scope 初始化，不因页面重挂载反复重试。前端在模型快照变化时重读本机报价，除 modelsFetchedAt 外也依赖整个模型快照，覆盖“刷新失败但成功时间不变”的情况；读取期间隐藏旧值。尺寸/质量等普通草稿参数变化不触发重新读取。

价格错误不改变模型检查成功/失败，不阻止生成。“保存并验证”没有新增事务提交后 await，保持原子返回和取消/版本/线路冲突语义。

## 协议及安全边界

沿用受保护的 GET /api/nova/connections/:id/pricing。仅 route-policy 的两个精确内置 OpenSosen HTTPS 源支持，读取选定 cn/com origin 的 /api/pricing，不带 /v1 前缀；不开放任意主机。

公开请求不调用 getAuth、不读取凭据，不发送 Authorization 或本地会话头。redirect:manual，只接受 HTTP 200，拒绝显式 success:false；读取总预算 8 秒、最多 1 MiB。仅投影型号、参考分组、单张数值、原因及连接/线路元数据。

保留严格固定按张校验：quota_type=1、有限非负基础价；存在表达式时只接受已知的 tier("image", fixed(base)) * image_count 形态，fixed 数字须与基础价一致。表达式仅识别，不执行。重复型号、未知计费模式、该精确分组未启用或其倍率异常均不可用；其他分组倍率不参与计算。连接或线路已变化的回执标 stale 且不附报价，前端也按冻结身份拒绝迟到值。
