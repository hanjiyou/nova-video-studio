# 更新安装与诊断补强计划

范围：修正交互安装器的窗口参数；工作台只提示真正需要处理的连接问题；补充跨启动脱敏诊断。先计划后实施，不发布、不调用真实生成服务、不启动安装器。

1. 保留现有安装准备/保存/数据库关闭/进程启动证明，交互安装明确允许窗口显示。历史 B 电脑卡住与隐藏参数相关只是待复现假设。
2. 工作台移除成功、未验证、五分钟过期横幅。设置页保留手动连接检查；缺凭据、无法解密、明确检查异常仍给可操作提示。
3. 复用 SQLite 中每任务 96 条诊断（前 16 条+滚动尾部）与单调时间摘要，补查询请求/响应/错误及安全网络错误分类、会话关联、恢复事件。上传/提交等待不能断言等于服务端计算时间。
4. 在应用自身资料目录保存独立、有上限、同步落盘的更新诊断文件，记录会话/尝试、检查/下载/保存确认/关闭/启动安装器/父进程退出/下次版本观察；后端关闭后仍可记录，下次导出合并。只保存固定枚举、数字和生成的 UUID，不保存原始异常、参数、地址、路径或凭据。写入失败不影响业务并报告诊断健康状态。
5. 增加隐私、容量限制、重启保留、更新失败与交互窗口参数测试；执行相关测试和完整前端类型检查。

边界：父进程退出后无法继续观察安装器，不能把 spawn 或下次版本相同当作自动安装成功；客户端日志不能证明 VPN 状态或上游内部根因。真实 Windows A→B 更新仍待新包验证。
