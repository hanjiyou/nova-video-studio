## 参数与证据边界

- 6s 默认6秒，允许1..6整数；preview默认10秒，允许1..15整数。默认值按连接身份和完整型号保存，上限不可由用户随意扩大。
- 6s单价5分/秒，preview20分/秒，来源为用户确认的配置。未读取或覆盖不明单位的价格接口。
- preview的四种候选尺寸为1280x720、1920x1080、720x1280、1080x1920；自定义仅验证正整数且JS安全整数，不宣传供应商像素上限/倍数。
- preview即使重新出现在清单，也仍受未验证协议门槛限制；目前只完成预备接入和离线参数验证。
- 6s既往只有5/6秒成功证据；带图不传size、其余秒数未在本轮调用真实服务。本轮没有读取真实Key、发外部生成或消耗额度。
- 参考图应用防护上限仍为7，明确不等于preview供应商上限；原别名共享文件保护未修改。
- 老草稿若含旧size保留并提供明确移除操作，不静默删除；老任务继续按原能力版本和输入快照执行。
- 图片界面没有增加模式tab或图片编辑器，费用说明仅在按钮上方，未加独立示例底栏。

## 2026-10-25 主审返修与复测

主审发现的三个问题均已修复：
1. 清单刷新进行中时，读取方先等待同一连接版本的刷新结果，再考虑成功缓存。界面收到有效最新结果后才确认处理；同步失败后由已有任务列表更新提供重试机会，按连接版本合并请求并退避30秒。连接切换后的迟到响应不应用。
2. 成功缓存10分钟与失败退避30秒分别判断。最近检查失败时，旧成功时间不再阻止退避期满后的重新检查；明确鉴权失败仍阻止生成，恢复成功才解除。
3. HTTP新响应严格验证型号记录与可选端点类型字段，任一畸形条目使整次刷新失败并保留原清单及成功时间。合法空数组仍可标记型号缺失；存储中的历史字符串数组保持兼容。

修改 backend/connections/service.js，新增 frontend/src/hooks/useRejectedModelRefresh.ts，并在 WorkbenchShell 中接入。新增后端3项回归、前端4项回归。workbench-connections 的清单正常路径夹具移除非法型号条目，其拒绝行为由新的畸形响应测试覆盖；凭据脱敏断言保留。

复测：原报告所列后端命令163/163通过；原前端目录命令含新增 model-refresh.test.tsx，共12文件90/90通过；完整 tsc 无诊断；git diff --check 通过。
