## 本批范围

- D01：追加 v9，旧 v1–v8 SQL/checksum 不改。任务生命周期版本 2 新增 generationOutcome/generationFinishedAt；旧行仍版本 1。下载尝试允许 waiting 的 startedAt/deadlineAt 为 null，执行开始后预算不可改。taskExecution 新增图片/视频下载秒数，默认 30/180，整数 30–1800；生成默认仍 120/300。旧四字段读取补默认，合法旧四字段写入显式保留当前数据库下载值并校验 revision，部分五字段拒绝。
- D02：有效结果与生成完成事实、waiting 下载尝试同事务登记，再关闭原生成 runtime。首次下载与手动重试均冻结配置，实际执行时才开始完整预算；同类并发与真实 IO 上限不变。原生成结论/时间保持；localOutcome 首次本地处理结束才写入，重试不覆写。新下载绝对截止贯穿刷新、多个文件、校验及保存；旧 v1 首次下载保留原总截止与 120 秒子上限。
- D03：独立进度采样器，3 秒滑动窗口、100ms 有界字节桶（最多约31个）、500ms 普通采样，首包/阶段/文件边界立即更新。3 秒无新字节速度归零，5 秒显示停滞观察。合法且与解码后响应字节口径一致的 Content-Length 才可计算比例；未知/压缩转换为 null，非法或矛盾长度失败。字节100%仍需校验、保存和关联事务。跨刷新复用同一采样器，真实网络累计与有效文件量分开。
- 最小跨层兼容：同一 store 投影合并内存进度，5秒/阶段持久化；首次下载不标为重试，waiting 不造日期，生成时间按 generationFinishedAt 冻结。前端新增 DTO 和现有说明，不实现新的下载进度卡片/配置输入。
