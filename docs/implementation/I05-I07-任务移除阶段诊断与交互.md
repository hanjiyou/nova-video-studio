## 行为与边界

I05 使用既有 v7 workbench_removed_tasks，仅从工作台最近图片/视频结果及任务展示移除。任务、幂等 localRequestId、快照、资产关联、文件及诊断保留；重启后范围一致。scope=workbench 为默认；作品库显式 scope=library，继续保留原 workbench_hidden_tasks 与 DELETE/deleteOutputs 的库隐藏和独占文件删除语义，不恢复旧隐藏。原共享/物理别名保护回归通过。活动任务与活动 downloadAttempt 都要求先取消、等服务确认，再移除；不根据原生成 localOutcome 单独判断当前活动。

I06 追加 diagnostic-timeline.js，复用 task_events，无 schema 迁移、无历史 SQL/checksum 变动。图片记录请求头/完整正文/解析、结果来源分类，下载记录下载/验证/保存与已知字节。视频记录参考图准备、收到真实 ID 的边界、状态变化、remote_waiting 和受限查询计数/失败分类。每次成功查询不重复切接收/解析阶段或写同状态 task_transition。生成与最新下载各一条摘要、诊断边界最多 96 条，保留前 16 条与最新尾部；溢出不丢终态和完整可观测阶段汇总。

诊断采集与导出双重白名单，字段仅为有限阶段/状态/错误分类、计数、HTTP 状态、来源类别、时间、UUID 与字节数。合成秘密、URL 参数、prompt、header/body、媒体和原始 error 不进入诊断。旧行无证据为 null。阶段与总执行耗时用运行上下文新增只读 elapsedMs() 钩子，取单调毫秒，不改变已审核截止/调度。进行中不以墙钟补齐；同 attempt 跨重启缺口标 unknownDurationPhases/elapsedUnknown，executionMs 未知为 null；第二次新的下载 attempt 重新建立可知测量。queueClock=wall_timestamp_estimate 明示队列时长只是持久墙钟估计。没有推算模型内部耗时或归因 VPN。

I07 在设置页加入独立 TaskExecutionSettings，未配置连接也可修改两类并发与时限。默认 3/3 和 120/300，范围 1–5 与 30–1800；完整值带 expectedRevision 保存，读取/保存失败可恢复，冲突保留输入并要求明确重读，dirty/保存中阻挡更新安装。修改并发只影响后续入场，时限只影响新任务。卡片/详情显示真实阶段、排队和执行时限/截止、冻结原生成终态计时、独立下载重试计时。卡片计数明确“当前显示”，仅统计实际展示的最多六项。

卡片与详情提供取消/结束后移除；取消失败或尚未确认不隐藏。移除清除选中详情/预览，hook 和详情同时防迟到列表/GET 复活；库中作品继续可读/另存/复用。视频停止查询保留原时限和名额，恢复只查询同 ID；结束/过期不可恢复。无 ID 的旧同步图片不提供伪造补 ID/查询操作。界面移除旧唯一占位/等待明确终态文案，无伪造百分比。

本地创建收到 ACK 即释放创建锁；慢详情/提醒清理不会锁住另一草稿。提交指纹和持久意图继续防双击/重复创建；未知 ACK 保持核对保护。activeSubmit/latestAcknowledged/reconcileSequence 保证旧 finally 不释放新创建锁，迟到列表不清新未知意图，旧详情不抢新任务/另一模式选择。未改图片/视频能力门槛、请求参数或远端取消协议。
