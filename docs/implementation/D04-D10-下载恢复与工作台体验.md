# D04–D10 下载恢复与工作台体验实施记录

开发日期：2026-10-25–26。状态：实现与离线验收完成，主会话源码与离线范围审核通过；未提交、推送、打包、发布或安装。

## 已落地范围

- D04：追加 v10，保留 v1–v9 的 SQL/checksum。requestId 原子回执、单活动尝试、acceptedAttemptId 与当前任务投影，回执丢失重放不会创建新尝试。旧客户端无 requestId 仅保留兼容，当前界面必传。已保存文件按任务、候选清单 outputSetId、槽位及白名单来源摘要建立检查点；重试重新读文件核对摘要。刷新原 ID 返回新清单时保守重新下载，不因 URL 相同假定内容相同。全部检查点有效时可直接恢复最终关联，不强制刷新失效源。仅完整文件复用，不支持字节断点续传。
- 来源存储保持原规则（用户最终确认）：安全持久 URL、内联资产和原 ID 查询可跨重启恢复；无 ID 临时签名地址仅在内存，重启后无法恢复时明确提示，不新增恢复密文。全部检查点文件已验证有效时可恢复最终关联。过期链接且没有原 ID 的结果不会重新生成。
- D05：持久 task.revision，任务变更、移除、资产可用性和节流进度发布递增；普通进度最多 500ms 发布（轻量 revision 写库约每活动任务 2 次/秒），快照约 5 秒/阶段保存。重启不倒退。HTTP 列表、单条、动作、既有鉴权 WS 同投影；终态订阅保留供手动重试。前端共享缓存拒绝旧/相同 revision，移除另存会话 tombstone，任务级重试锁和未确认 requestId 跨卡片/详情共享。
- D06：原任务卡片、预览和详情内共享 DownloadStatus，布局不另加区域。图片/视频阶段、实际字节/可信总量/速度、未知总量、文件序号与整体保存数、复用文件明确显示；失败后重新下载、活动时取消下载。字节 100% 仍显示校验/保存，完成且文件完好后收起过程。超过 5 秒无新 revision 显示进度暂不可用并归零速度。完整生成耗时冻结，截止时间仅详情。
- D07：设置页 2 项并发 + 4 项时限，下载默认图片 30/视频 180 秒，整数 30–1800；生成默认 120/300。排队冻结、实际执行计时；新设置影响下一次尝试，运行中不改。明确升级后新任务分阶段、旧任务保持历史规则。
- D08：尝试终态幂等，迟到清理不覆盖新尝试摘要。导出最近 10 次和总次数/省略数，含失败字节、总量、耗时、HTTP 状态、预算、原因、复用、停滞次数及最后停滞时间。采集和导出白名单；系统代理接管为 unknown，direct 只表示应用请求策略。等待取消、重启中断同样有原因。单独区分 CDN 403 拒绝访问，不能一律解释地址过期。
- D09：合成文件、本地 loopback HTTP、隔离 SQLite、假凭据与假时钟；不访问真实生成、真实用户库或代理设置。
- D10：契约、操作说明、规划和台账同步，最终主审与交付准备分开；源码开发验收不要求发布后才能结束。
