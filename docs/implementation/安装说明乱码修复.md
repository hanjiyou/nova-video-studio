# 安装说明乱码修复（2026-10-25）

## 先行计划

限定范围：两个安装说明文本的编码标记、更新构建前编码校验及对应测试。保留中文正文，不修改业务逻辑，不提交、不构建、不安装、不发布，不修改已发布 3.6.3 字节。

1. 核对固定依赖 app-builder-lib 的 NSIS license 处理：显式 nsis.license 路径直接输出 MUI_PAGE_LICENSE，提前返回；自动本地化 license 路径才调用 convertFileToUtf8WithBOMSync。
2. 为 GITHUB-TEST-NOTICE.txt 和继承基础配置使用的 LOCAL-TEST-NOTICE.txt 添加 UTF-8 BOM，保持原有正文与换行字节不变。

4. 增加回归：仓库两个真实文本、临时无 BOM/错误 UTF-8、构建入口拒绝无 BOM。运行已有构建验证测试。
