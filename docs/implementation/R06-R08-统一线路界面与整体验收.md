# R06–R08 统一线路界面与整体验收

日期：2026-10-26。状态：第二批界面、前端离线回归和共享文档完成，已通过主会话源码与离线范围审核。第一批后端已通过源码与离线范围主审，见[第一批实施](R01-R05-统一线路后端实施记录.md)。两批实施安排保持；本轮未提交、推送、打包或发布。

## 已实现行为

- 设置和首次引导的内置OpenSosen连接提供国内cn默认、国际com选择，显示实际所选只读地址、当前保存目标和只读models目标。内部保留原baseUrl身份，线路保存不换connectionVersionId、不索要旧Key。
- 自定义服务不显示不适用选项，地址仍可编辑；改为其他地址仍需Key。旧摘要缺route字段时保留原地址与检查目标，不倒推已保存cn、不假装旧宿主支持线路。
- 保存/候选验证透传route及现有连接expectedRouteRevision；HTTP只读check附带已知修订。线路编辑参与dirty、更新安装阻止、候选取消和引导修订保护。保存失败/冲突保留输入，只有保存成功才清空Key。
- 冲突可重新读取线路与版本，同时同步外层当前连接。表单按稳定connectionId保持生命周期，版本变化不重建表单丢失名称、地址、线路或Key；用户核对后再次保存/测试。
- 工作台模型清单接受当前连接版本与已知route/revision；切线不换连接版本也能阻止迟到旧清单。型号拒绝仅匹配任务原连接版本和明确线路；新摘要下历史缺线路不假定cn，旧宿主无新字段仍走兼容路径。仅设置/清单做此过滤，已发出生成结果不因此丢弃。
- 提交前只读检查发生线路冲突时直接停止，尚不保存意图或发送生成POST。任务、DownloadAttempt前端DTO增加可空transportRoute；models.transportEvidence两值分别表达cn未验证或查看具体能力证据，不宣称com所有模式verified。
- 帮助文字明确新任务和后续查询/新的重新下载尝试使用所选线路，已发出请求保持原线路；线路不控制VPN、不承诺更快。原下载状态提示修复保留并参加回归。

复用现有preload和IPC，未新增通用接口、框架或跨端重构。本批未修改backend或desktop；后端记录和主审JSON由第一批/主会话维护。
