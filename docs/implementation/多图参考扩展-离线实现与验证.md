- 原双图标签改为“多图参考”；保留原草稿槽和原双图能力，2 张继续走 `video.dual_reference`，3..7 张走新增 `video.multi_reference`。
- 多图导入、拖动/按钮排序、移除、跨页作品选择和历史复用保留全部素材与顺序；不截断、不将缩略图代替原始 PNG/JPEG。
- 视频多图预算独立集中在 `backend/storage/application-limits.json` 的 `maxVideoReferenceAssets`，按用户要求设为 7，配置范围 3..7；视频界面、提交校验和适配器共同读取，插件 manifest/schema 也设为 7。通用素材导入/存储的 `maxReferenceAssets` 保持原 32，不改动历史素材；供应商数量上限未知。
- 新多图能力有独立不可变版本 `opensosen-multi-reference-unverified-2026-10-24-v1`，仅匹配 OpenSosen 原地址、OpenAI 协议、`grok-imagine-video-1.5-6s` 和插件 1.1.0。记录仍是 unverified、无真实成功 sourceIds、applicationVerified=false；6 秒/1280×720 是尝试参数。
- 用户可从正常生成按钮主动提交，不加确认勾选；界面明确提示 3 张以上尚未实测、结果以服务返回为准、可能失败或计费。通用 `generationEvidenceVerified` 不变，其他未验证组合继续关闭。
- 插件升至 1.1.0；旧 1.0.0 仅精确原文生/单图/双图模式兼容。旧 localRequestId 返回原任务并保留冻结快照；新多图不能通过旧版本。未知提交保留生成占位，重启与重放不自动再次 POST。
